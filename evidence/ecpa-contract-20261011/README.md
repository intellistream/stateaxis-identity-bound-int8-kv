# ECPA activation-contract evidence

Label: `manager-contract-identity-bound-int8-kv-non-performance`.

Extension Manager verifies the research-manifest digest and emits the reviewed
audit-only INT8 KV schema. StateAxis independently validates the identity,
binds it into assembly/state-graph hashes, and counts candidate KV writes and
projected storage bytes. BF16 remains authoritative and the accuracy-negative
device consumer is not dispatched.

This is assembly and deterministic effect-counter evidence, not an accelerator
performance measurement.
